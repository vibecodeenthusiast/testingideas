A powerful and flexible quiz builder plugin for WordPress.

== Description ==

Quiz Builder is a comprehensive solution for creating and managing interactive quizzes on your WordPress site. With an intuitive admin interface, you can easily create quizzes, manage a question bank, and embed quizzes anywhere on your site using shortcodes.

Features:
* Intuitive quiz creation interface
* Question bank management
* Flexible question types with category support
* Beautiful frontend display
* Shortcode support for easy embedding
* Responsive design
* Detailed result reporting

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/quiz-builder` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the Quiz Builder -> Add New menu to create your first quiz
4. Embed quizzes using the [quiz id="quiz_id"] shortcode
